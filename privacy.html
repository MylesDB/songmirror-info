Privacy policy

This policy covers MylesDB’s personal SongMirror installation and this information website. It does not describe every installation of the upstream SongMirror project.

Information the private app uses

To sync playlists, the app accesses playlist names and identifiers, track metadata and service identifiers, and the selected Google/YouTube identity’s playlist and library information. Google OAuth access and refresh tokens are used to maintain authorized access. Spotify connection credentials are used to read the selected source library.

How information is used

Data is used to read the selected source playlists, match recordings, create or update destination playlists, and show sync status. Local caches, mappings and job records support matching, repeat runs and troubleshooting. Changes to destination playlists follow the configured sync rules.

Storage and sharing

Connection credentials and app data are stored on the owner’s self-hosted server. The app sends requests and necessary metadata to Spotify and Google/YouTube to authenticate, search for matches and synchronize playlists. The resulting playlists are stored by the destination service under that service’s terms and the account’s playlist visibility settings.

This installation does not sell Google user data, use it for advertising, or publish credentials or library data to this website or its repository. Google user data is not used to train generalized artificial intelligence or machine-learning models. Its use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention, revocation and deletion

Stored tokens, cached metadata, mappings and sync records remain on the private server until removed by the owner. Access can be revoked at any time through Google Account connections. Revoking access stops future authorized Google access; it does not automatically erase local caches or playlists already created. The owner can remove stored app data on the server and delete destination playlists through YouTube Music. Any retained backups must also be removed to erase their copies.

This public website

This is a static GitHub Pages site. It has no sign-in form, analytics scripts or application cookies, and receives no SongMirror account credentials or playlist contents. GitHub may process technical visitor information, such as IP addresses, to host and secure the site, as described in the GitHub Privacy Statement. Following an external link makes that service’s privacy practices applicable.

Contact and updates

For questions, contact the installation owner through GitHub issues. Issues are public: do not include credentials or personal library data. Updates to this policy will appear here with a revised date.
